# MektepApp AI — учебный ассистент на Streamlit + Gemini

Локальное веб-приложение для студентов: конспекты с экспортом в Word, решение Excel-задач с готовым файлом `.xlsx` и быстрый разбор домашних заданий. Работает на моделях Gemini Flash (по умолчанию `gemini-flash-latest`) через официальную библиотеку [`google-genai`](https://pypi.org/project/google-genai/).

## Возможности

- **Конспектирование и Q&A** — тема, текст или файл (PDF, DOCX, TXT, MD) превращаются в структурированный конспект: главные мысли, разделы, термины и вопросы для самопроверки. По материалу можно задавать вопросы в чате. Конспект скачивается в Word (`.docx`) или Markdown.
- **Генератор Excel-задач** — расчёты, таблицы и учёт: пошаговое объяснение и настоящий файл `.xlsx` с живыми формулами, итоговыми строками и отдельным листом «Решение».
- **Быстрое решение ДЗ** — чат-репетитор с потоковыми ответами, формулами LaTeX и поддержкой фото задач.
- Тёмная тема, язык ответов (русский, қазақша, English), уровень обучения, переключатель «Глубокое мышление», понятные сообщения об ошибках и кнопка «Повторить».

## Быстрый запуск

Нужен Python 3.10 или новее.

- **Windows:** дважды щёлкните `run.bat`. Он создаст окружение `.venv`, установит зависимости и откроет приложение в браузере.
- **macOS / Linux:** выполните `./run.sh`.
- **VS Code:** откройте папку проекта и нажмите F5 (конфигурация «MektepApp AI (Streamlit)»). Зависимости должны быть уже установлены, например через `run.bat`.

Ключ можно вставить в `.env` или ввести в боковой панели приложения.

## Запуск вручную

```bash
pip install -r requirements.txt
cp .env.example .env        # и вставьте свой ключ в GEMINI_API_KEY
streamlit run app.py        # или: python app.py
```

Бесплатный ключ выдаётся в [Google AI Studio](https://aistudio.google.com/apikey). Его также можно ввести в боковой панели и сохранить в `.env` кнопкой «Сохранить в .env». Файл `.env` добавлен в `.gitignore`.

## Модель

По умолчанию используется `gemini-flash-latest` — псевдоним Google, который всегда указывает на актуальную модель Gemini Flash. Если выбранная модель снята с поддержки (ошибка 404), приложение само переключится на `gemini-flash-latest`. Другую модель можно выбрать в боковой панели или указать в `.env`:

```bash
GEMINI_MODEL=gemini-2.5-flash
```
